## 📖 Sobre el Proyecto

Este repositorio aloja el portfolio personal de **Martín Ratti**, estudiante avanzado de **Ingeniería en Sistemas (UTN Rosario)**. Más que una simple presentación, este sitio es una demostración técnica de capacidad de desarrollo, combinando rendimiento extremo con un diseño moderno.

### 🌟 Características Principales
* **Performance First:** Construido sobre **Astro 5** puro (sin runtime de frameworks pesados en el cliente) para tiempos de carga instantáneos.
* **UI Moderna:** Diseño **Glassmorphism** con animaciones fluidas y **Dark Mode** totalmente integrado.
* **Internacionalización (i18n):** Contenido disponible en Español 🇪🇸 e Inglés 🇺🇸.
* **Type Safety:** Código robusto desarrollado en **TypeScript**.
* **SEO Optimizado:** Meta tags dinámicos, JSON-LD y Open Graph para redes sociales.

## 💻 Proyectos Destacados

Algunos de los proyectos que demuestran la aplicación de este stack:

### 🛍️ PCFIX - E-Commerce Monorepo
Plataforma de comercio electrónico de alto rendimiento.
- **Stack:** Astro, React, Express, PostgreSQL, Docker.
- **Arquitectura:** Monorepo con panel administrativo y Business Intelligence.

### 🚗 EstacionAR - Smart Parking
Plataforma mobile-first para gestión y reserva de estacionamientos.
- **Stack:** React Native, Node.js, PostgreSQL, Turborepo.
- **Features:** Geolocalización, reservas en tiempo real y pagos integrados.

### 🤝 ImpulsaMe - Crowdfunding
Plataforma de financiamiento colectivo con moderación.
- **Stack:** Java, JSP, Servlets, MySQL, Maven.
- **Arquitectura:** MVC puro sin frameworks, demostrando fundamentos sólidos.

## 🚀 Instalación

Si deseas clonar o contribuir a este portfolio:

```bash
# 1. Clonar repositorio
git clone https://github.com/martin-ratti/Portfolio.git
cd Portfolio

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
# Disponible en http://localhost:4321
```

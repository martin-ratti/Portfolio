# AGENTS.md

## Project Overview
This is the personal portfolio website of Martín Ratti, a Full Stack Developer and Systems Engineering student. The project is built with pure Astro 5, TypeScript, and Tailwind CSS v4, featuring a modern Glassmorphism design, internationalization (ES/EN), and an AI assistant ("Martín AI").

## Tech Stack
- **Core:** Astro 5, TypeScript
- **Frontend & Styling:** Pure Astro components, Tailwind CSS v4, Glassmorphism UI, Dark Mode support
- **I18n:** English and Spanish support

## Setup Commands
- Install dependencies: `npm install`
- Start dev server: `npm run dev` (running on http://localhost:4321)
- Build for production: `npm run build`

## Code Style
- **Framework:** Astro components (.astro) are the main building blocks.
- **Logic:** TypeScript for type safety.
- **Styling:** Tailwind CSS utility classes and global CSS variables for themes.
- **Directory Structure:**
  - `src/components`: UI components
  - `src/pages`: Routes and pages
  - `src/layouts`: Layout wrappers
  - `src/utils`: Helper functions (including i18n logic)

## Key Features
- **Performance:** Optimized for speed with Astro.
- **Accessibility:** Semantic HTML and ARIA labels where appropriate.
- **SEO:** Dynamic meta tags and Open Graph support.
